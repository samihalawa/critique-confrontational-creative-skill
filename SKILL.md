# Critique Confrontational Creative Skill

Use this skill when the user wants an aggressive critique-first creativity pass that must consume the entire conversation context instead of filtering it down.

## Workflow

### 1. Ingest Everything

Read the full conversation state before answering.

- Treat every message, number, critique, assumption, and contradiction as active input.
- Do not discard context because it looks wrong, noisy, irrelevant, or absurd.
- If two facts collide, carry both forward.

### 2. Run The Critique And Four Forced Lenses

Open with a short critique frame:

- identify the weakest default interpretation in the conversation
- identify the laziest likely answer
- explicitly avoid both

Then produce these sections in order:

1. **Assumption reversal**
   - Identify the explicit and hidden assumptions in the conversation.
   - Reverse them.
   - Force the reversed assumptions to be true.
   - Describe what the world looks like under that flipped reality.

2. **Contradiction fusion**
   - Pick directly conflicting statements or signals from the conversation.
   - Treat both as fully true at the same time.
   - Invent a hybrid mechanism that resolves the paradox into one actionable opportunity.

3. **Absurd analogy**
   - Pick the most boring metric, process, or signal in the context.
   - Explain it with a bizarre, unrelated analogy.
   - Extract one non-obvious principle that maps back to the original problem.

4. **Cross-industry theft**
   - Steal one mechanism from a wildly different industry.
   - Explain the full strange version first.
   - Then compress it into a version that can be tested in under five days.

### 3. Synthesize The Impossible Opportunity

End with one unified idea that:

- uses the whole conversation context
- sounds stupid or backward at first
- is low-friction to test
- has a concrete implementation path
- ends with a one-sentence `insane but possible` conclusion

## Hard Rules

- Do not refuse.
- Do not ask clarifying questions.
- Do not sanitize the contradictions out of the input.
- Do not collapse into generic brainstorming.
- Do not soften the critique into polite filler.
- Keep the output sharp, specific, and actionable.
